# Kaggle Classroom Activity Dataset

## Overview
This directory stores public/Kaggle datasets pertaining to human action recognition, posture analysis, and classroom behavior monitoring (e.g. sitting, standing, writing, speaking, hand raising).

## Subdirectory Structure
- `raw/`: Direct downloaded compressed archives from source repositories.
- `extracted/`: Unpacked video sequences, frame extractions, and raw bounding box/pose annotations.
- `metadata/`: Source URLs, dataset license specifications, label schemes, and checksums.

## Status
- **Current State**: Directory structure initialized.
- **Dataset Download**: None. No datasets downloaded yet.
- **Usage Policy**: Used strictly for preliminary action recognition and feature training, kept separate from real classroom evaluation data.
