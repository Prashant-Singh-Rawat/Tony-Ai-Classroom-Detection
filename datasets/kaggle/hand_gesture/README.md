# Kaggle Hand Gesture Dataset

## Overview
This directory stores public/Kaggle hand gesture datasets utilized for initial pre-training, transfer learning, and feature representation for hand gesture and hand-raise detection tasks.

## Subdirectory Structure
- `raw/`: Unmodified downloaded dataset archives (e.g. `.zip`, `.tar.gz`) as fetched directly from Kaggle.
- `extracted/`: Extracted image frames, cropped gestures, and raw annotation files.
- `metadata/`: Provenance metadata, licenses, split definitions, and dataset registry records (`dataset_info.md`).
