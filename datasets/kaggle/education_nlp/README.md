# Kaggle Education NLP Dataset

## Overview
This directory stores public datasets for educational natural language processing, lecture transcript modeling, topic segmentation, educational question-answering, and RAG retrieval benchmarks.

## Subdirectory Structure
- `raw/`: Unprocessed corpus files, raw transcript dumps, and source QA/quiz datasets.
- `processed/`: Cleaned text corpora, chunked transcripts, normalized tokens, and sentence embedding test matrices.
- `metadata/`: Corpus provenance, language information, licensing, and vocabulary statistics.
